## Estructura del repositorio

```
Carrera Arquitechthor/   ← Archivos Markdown (fuente de contenido)
docs/                    ← Sitio web (GitHub Pages)
  ├── index.html
  ├── css/style.css
  ├── js/
  │   ├── config.js      ← Edita aquí para agregar nuevo contenido
  │   └── app.js
  └── content/           ← Copia de los Markdown servida por la web
```

## Agregar contenido nuevo

1. Agrega tu archivo `.md` en `docs/content/Carrera Arquitechthor/` (y en `Carrera Arquitechthor/` si quieres mantener ambos).
2. Abre `docs/js/config.js` y agrega una entrada siguiendo el patrón documentado al inicio del archivo.
3. Haz commit y push — GitHub Pages se actualizará automáticamente.
