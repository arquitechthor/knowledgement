Amazon S3 (Simple Storage Service)

Amazon S3 es un servicio de almacenamiento de objetos altamente escalable, seguro y duradero en la nube de AWS. Permite almacenar y recuperar cualquier cantidad de datos desde cualquier lugar.

Características principales

  • Escalabilidad ilimitada: almacenamiento prácticamente infinito.
  • Alta durabilidad: 99.999999999% (11 nueves).
  • Disponibilidad: acceso a datos en cualquier momento.
  • Seguridad: control mediante políticas, cifrado y control de acceso.
  • Clases de almacenamiento: Standard, IA, Glacier, entre otras.

Conceptos clave

  • Bucket: contenedor donde se almacenan los objetos.
  • Objeto: archivo almacenado junto con sus metadatos.
  • Clave (Key): identificador único del objeto dentro del bucket.

Casos de uso

  • Backup y recuperación
  • Hosting de webs estáticas
  • Almacenamiento de logs y datos
  • Data lakes

AWS IAM (Identity and Access Management)

IAM es el servicio de AWS que permite gestionar el acceso a recursos mediante usuarios, grupos y roles, controlando quién puede hacer qué dentro de la cuenta.

Características principales

  • Gestión de identidades: usuarios, grupos y roles.
  • Control de acceso: mediante políticas basadas en JSON.
  • Seguridad: autenticación multifactor (MFA).
  • Acceso granular: permisos detallados por recurso y acción.

Conceptos clave

  • Usuario: entidad con credenciales para acceder a AWS.
  • Grupo: colección de usuarios con permisos comunes.
  • Rol: identidad asumible temporalmente por usuarios o servicios.
  • Política: documento JSON que define permisos.

Buenas prácticas

  • Aplicar el principio de mínimo privilegio
  • Usar roles en lugar de credenciales embebidas
  • Activar MFA para usuarios sensibles
  • Rotar credenciales periódicamente
